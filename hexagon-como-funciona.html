El problema y la arquitectura
1

¿Por qué hexágonos en lugar de puntos?

Con millones de puntos, incluso con deck.gl WebGL, llega un momento en que pintar punto por punto no da información clara: en zonas densas todo se superpone y no se distingue nada.

La solución es agrupar los puntos en celdas y colorear cada celda según cuántos puntos contiene. La forma elegida es el hexágono, y el sistema que lo hace eficientemente es H3.

El sistema H3: celdas hexagonales jerárquicas

H3 es un sistema creado por Uber que divide toda la superficie terrestre en hexágonos. Lo que lo hace especial es su naturaleza jerárquica: tiene 16 resoluciones (0 a 15), y cada hexágono de resolución N contiene exactamente 7 hexágonos de resolución N+1.

3

Resolución automática por zoom

El núcleo del sistema es un mapeo de zoom de Google Maps a resolución H3. Cada vez que el zoom cruza un umbral se recalcula la agrupación.

// Tabla de umbrales zoom → resolución H3
const ZOOM_RES = [
  [4,  3],  // zoom ≤4  → hex ~86,000 km²
  [6,  4],  // zoom ≤6  → hex ~12,000 km²
  [8,  5],  // zoom ≤8  → hex ~252 km²
  [10, 6],  // zoom ≤10 → hex ~36 km²
  [12, 7],  // zoom ≤12 → hex ~5 km²
  [14, 8],  // zoom ≤14 → hex ~0.7 km²
  [100, 9]  // zoom >14 → hex ~0.1 km²
];

MAP.addListener('zoom_changed', () => {
  const newRes = getResForZoom(MAP.getZoom());
  if (newRes !== currentRes) {
    currentRes = newRes;
    // Debounce 300ms: espera que el usuario termine de hacer zoom
    clearTimeout(zoomDebounce);
    zoomDebounce = setTimeout(() => regroup(), 300);
  }
});
💡
¿Por qué solo cuando cruza un umbral? El zoom de Google Maps es continuo — si reagrupáramos en cada micro-cambio de zoom lanzaríamos cientos de cálculos por segundo. Los umbrales garantizan que solo se reagrupa cuando realmente cambia el nivel de detalle.

Web Worker: cálculo sin congelar la UI

Asignar 4 millones de puntos a celdas H3 tarda varios segundos. Si se hiciera en el hilo principal, la página quedaría congelada durante ese tiempo. La solución es un Web Worker: un hilo separado que hace el cálculo mientras la UI sigue siendo usable.

buildHexLayer()
// Worker inline (Blob URL) con h3-js via importScripts
importScripts('https://unpkg.com/h3-js@3.7.2/dist/h3-js.umd.js');

self.onmessage = function(e) {
  const { lats, lngs, resolution } = e.data;
  const hexMap = {};

  for (let i = 0; i < lats.length; i++) {
    // Asignar cada punto a su celda H3
    const hex = h3.geoToH3(lats[i], lngs[i], resolution);
    if (!hexMap[hex]) hexMap[hex] = { hex, count: 0 };
    hexMap[hex].count++;
  }
  // Devolver array de hexágonos al hilo principal
  self.postMessage(Object.values(hexMap));
};
⚡
Transferables para cero-copia. Los arrays Float64Array se pasan al worker como transferable objects: no se copian, se transfieren. Pasar 32MB de coordenadas tarda microsegundos en lugar de milisegundos.
5

H3HexagonLayer: renderizado con deck.gl

Una vez que el worker devuelve los hexágonos agrupados, deck.gl los renderiza con H3HexagonLayer. Este layer sabe convertir un ID de hexágono H3 a las coordenadas de sus 6 vértices para dibujarlo en el mapa.

new deck.H3HexagonLayer({
  id: 'hex',
  data: hexagons,             // [{hex, count}, ...]
  getHexagon: d => d.hex,     // ID H3 del hexágono

  // Color por densidad (escala logarítmica para mejor contraste)
  getFillColor: d => {
    const t = Math.log1p(d.count) / Math.log1p(maxCount);
    return lerpColor(colorScheme, t);
  },

  extruded: false,   // true → hexágonos 3D con altura = densidad
  coverage: 0.85,  // espacio entre hexágonos (0-1)
  wireframe: false, // solo bordes
  pickable: true,   // habilita hover/click
});

Modo Categorías: distribución aleatoria exacta

En lugar de colorear por densidad, el usuario puede asignar categorías a los puntos por cantidad exacta (ej: 1M rojos, 2M azules) y el sistema las distribuye aleatoriamente.

// 1. Construir secuencia [0,0,...,1,1,...] según cantidades
const seq = new Int8Array(totalAssigned);
let ptr = 0;
for (let i = 0; i < categories.length; i++) {
  for (let j = 0; j < categories[i].count; j++) seq[ptr++] = i;
}

// 2. Fisher-Yates shuffle → distribución aleatoria
for (let i = seq.length-1; i > 0; i--) {
  const j = Math.floor(Math.random() * (i+1));
  [seq[i], seq[j]] = [seq[j], seq[i]];
}

// 3. Worker cuenta categorías por hexágono
// 4. Hexágono se pinta con la categoría dominante
getFillColor = d => {
  let maxCat = d.cats.indexOf(Math.max(...d.cats));
  return catColors[maxCat];
};
